# Troubleshooting

Inspect the exact job ID/stage/error and preserve the source. A queued request is not a completed clip. `clipstudio capabilities`, `clipstudio job JOB_ID`, `clipstudio project PROJECT_ID` and `/docs` show the current installed behavior.

| Symptom | Cause and concrete recovery |
|---|---|
| UI says API unavailable | Start `./scripts/start.sh` from the project. Use `http://127.0.0.1:8741`. A different port requires matching `VEKTRI_PORT`. |
| API works but UI is a setup message | Run `cd frontend && npm ci && npm run build`; restart the local service so static assets mount. |
| Job stays queued | The supervisor may not be running or available RAM is below 1.5 GiB. Close unrelated heavy apps, inspect `clipstudio jobs`, and start the supervisor via the normal start command. Do not launch many workers to bypass the global cap. |
| `worker_active: false` on health | This field only reports an actively leased running job. An idle healthy worker can report false; inspect process/start terminal and queue. |
| Health lists more workers than expected | A worker outlived a `clipstudio serve` that died without cleanup (closed terminal, SIGKILL). Serve-managed workers now stop on their own when their supervisor disappears; an older orphan can be stopped with `kill -TERM PID` (it finishes gracefully and its lease expires). Transactional claims mean a second worker never corrupts jobs, but it keeps old code loaded. |
| Python package/MediaPipe-style incompatibility | Use this project's pinned Python 3.11 environment, not system Python 3.14 or a candidate audit environment. Run the native setup command and `uv sync --locked --extra dev`; do not install a candidate's entire stack into this environment. |
| Source rejected as a container | Confirm it actually plays locally. Corrupt files, HLS/M3U playlists, remote references, unsupported containers and frames above 40 megapixels are rejected. A renamed extension does not make a file valid. Local import remains available for supported real media. |
| URL rejected | Only direct HTTP/HTTPS public media is supported. Loopback/private/link-local/metadata addresses, blocked redirects, credentials in URLs, oversized/time-limited responses and platform web pages fail. Download through a permitted supported method yourself, then intentionally choose the local file; do not supply cookies or bypass access controls. |
| Upload interrupted | The resumable API records an offset. `GET /api/v1/uploads/UPLOAD_ID`, then `PATCH` the same upload with exact `Upload-Offset` and <=8 MiB chunks. Complete only after stored bytes equal declared length. A duplicate completed request returns the existing import job. The browser Pause button retains progress. Reselect the same file with matching project details to resume; changed inputs begin a distinct upload. |
| No audio stream | Manual edit/render still works. Output supplies silent audio for compatibility. Speech transcription returns honest no-audio/empty evidence; use visual heuristics or manual markers. |
| Several audio streams | Select the desired zero-based audio ordinal in the timeline audio setting (`stream_index`: 0 is the first audio track, 1 the second). Export validates it against metadata. The lightweight proxy preview remains the first track; listen to the completed export for the selected track. Transcription/analysis track selection is separate. |
| Rotated/VFR footage | FFmpeg autorotation normalizes preview/export, and output uses a selected constant frame rate. Source metadata preserves rotation/frame-rate/time-base. Browser frame stepping is approximate; inspect the exported frame and sync marker rather than asserting exact decoder seeking. |
| Local model missing | Inspect capability sizes/status and explicitly queue `download-model tiny.en` or `download-model minilm`. Manual editing/export do not need either. No cloud API is silently substituted. |
| Model checksum/download failure | Partial downloads do not become ready models. Check disk/network, inspect the job and retry the explicit download. Do not rename partial bytes or disable SHA-256 checks. |
| Non-English or inaccurate words | Select tiny.en for English, or explicitly install optional multilingual tiny and select the intended language. Correct words/times manually when needed. Broad language and real-human speech quality remain unvalidated. |
| No useful candidates | Check whether genuine local semantic mode or heuristic-only mode ran. Use shorter permitted lengths, more context, a grounded query or manual event marker. Do not force requested count by inventing useful moments. |
| Tracking jumps/misses | Detection is experimental. Choose the object region correctly, use smaller intervals, inspect scene cuts and confidence, or lock framing/use fit. It is not named-person recognition or active-speaker association. |
| Captions disappear or differ | Verify enabled/burn-in settings and real timed words. Clean exports have sidecars but no burn-in. Rendering groups/escapes words; preview is a browser representation. Use supported DejaVu Sans, Serif or Sans Mono; color/highlight accept #RRGGBB and stroke is 0–8 output pixels. Review actual output, long words, script shaping and system font coverage. |
| Audio sounds different in preview | Gain/fades/normalization are export processing; review a completed render for final audio. Manifest reports decoded sample peak, not a true-peak or perceptual mastering certificate. |
| Save returns 409 | Another revision or ASR/correction changed the project. Preserve unsaved JSON, reload current state and deliberately reapply the desired changes. Never overwrite by guessing revision numbers. |
| Agent proposal returns 409 | The evidence fingerprint is stale. Export a fresh packet and review against its current source/transcript/revision. |
| Export failed or canceled | The worker never marks partial stage files successful. Inspect the stage error, correct disk/model/input issues, then retry. Finished stages are fingerprinted and reusable. Originals remain intact. |
| Source checksum mismatch | Stop dependent work. Restore the original bytes from backup or create a new deliberate import. Do not replace the saved checksum to conceal a mutation. |
| Disk full | Cancel heavy work, inspect `clipstudio storage`, and move a verified complete backup or intentionally remove known expendable outputs only after review. There is no automatic original deletion. Rendering temporarily needs approximately 11 MiB per output minute for uncompressed stereo PCM, plus intermediate video and final files; disk preflight accounts for this audio space. |
| Interrupted worker | Restart normally. Stale 20-second leases become reclaimable; completed stages survive. Attempts are bounded to three. Repeated failure needs diagnosis, not endless automatic retries. |
| Publish returns 409 | Expected: no supported authorized posting adapter/account exists. The queue is local draft/manual handoff. Download the final package; posting is a separate operator action. |
| Manual approval invalidated | Timeline/transcript/draft changed or asset revision is stale. Render/review the current version and make a new explicit manual approval with exact destination/account/caption/visibility/schedule/time zone. |

Stop with Ctrl-C in the foreground start terminal. Restart with `./scripts/start.sh`. Data defaults to `./data` and is not in Git; setting `VEKTRI_DATA_DIR` selects a different library. Do not change that variable and conclude the prior library was deleted.

Use the full backup/restore procedure while the app is stopped and jobs are complete. Backups include original media and metadata; restoring into a new directory avoids silently overwriting an existing library. Public tunnels, deployment, live social connections and binary redistribution are not part of this local setup.
