# Contributing

This is an early public source release without a project-wide open-source license. Discuss substantial changes with the maintainer before investing in a contribution.

Keep changes focused and accompanied by regression tests. Run the Python suite, TypeScript tests and production frontend build, then exercise affected browser flows when a supported browser is available. Report skipped, blocked and unrun checks separately from passes.

Use original synthetic inputs for committed tests. Do not commit recordings, screenshots of private libraries, personal paths, credentials, databases, downloaded models, installed dependencies or raw internal reports. Preserve all third-party notices. Keep every capability claim tied to actual implementation and measured evidence.
